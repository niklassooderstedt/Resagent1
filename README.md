# DestyPoint v2.1

En fristående GitHub Pages-version av DestyPoint-framsidan.

## Publicera på GitHub Pages

1. Packa upp zip-filen.
2. Lägg **index.html**, **styles.css** och **script.js** direkt i repositoryts root (inte i en extra undermapp).
3. Commit + push.
4. Gå till **Settings → Pages** och välj rätt branch/root.
5. Öppna den GitHub Pages-adress som GitHub visar.

Viktigt: `index.html` måste ligga i den mapp som GitHub Pages publicerar. 404-felet i den tidigare versionen berodde sannolikt på att Pages inte hittade en `index.html` på den publicerade sökvägen.
