# DestyPoint v2.3

Mobile-first front page for DestyPoint, based on the approved v2.1 visual reference and the v2.3 refinements.

## v2.3 visual refinements
- Tighter hero composition and spacing to match the approved reference.
- Cleaner four-card inspiration row: Weekend, Roadtrip, Sol & bad, Natur & äventyr.
- Refined iconography and card proportions.
- Refined date fields, primary CTA and typography scale.
- Preserved the location-pin travel description field.
- Preserved the illustrated travel landscape/footer treatment.
- Natural-language travel prototype logic retained from v2.2.

## Run
Open `index.html` in a browser, or deploy the folder as a static GitHub Pages site.
