# DestyPoint v1.5 — UI redesign

Den här versionen bygger om prototypens användarupplevelse efter DestyPoint-mockupen:
- mörk marinblå premium-förstasida
- DestyPoint + kursiv tagline "Din AI-baserade resebyrå"
- "Beskriv din resa" som primär ingång istället för Kom igång/Logga in
- resultat i en mobil resebyrå-layout med destination, reseöversikt, boende, transport och uttryckligen nämnda aktiviteter
- inga påhittade aktiviteter
- boende visar tydligt att prototyppriset inte är ett livepris och reserverar plats för faktisk leverantör/källa

Detta är fortfarande en fristående HTML/CSS/JS-prototyp utan riktiga hotell-/flyg-API:er.
