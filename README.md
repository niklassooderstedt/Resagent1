# ResAgent v0.5
Första versionen med fritt resmål.

- Användaren kan skriva vilken plats som helst.
- Budget, datum och antal resenärer finns i gränssnittet.
- Prioriteringar kan väljas.
- Tre olika reseupplägg visas.
- Mobilanpassad.
- Simulerad data; inga riktiga bokningar eller externa API:er ännu.
