# DestyPoint v2.4

Mobile-first front page for DestyPoint, built from the approved v2.3 baseline and aligned to the approved visual reference.

## v2.4 changes
- Reworked the mobile home-screen composition to closely match the reference image.
- Reduced vertical scale and spacing across logo, title, planner, dates, CTA and inspiration cards.
- Moved “Från” and “Till” labels into the date cards to match the reference.
- Preserved the v2.3 travel description field, inspiration interactions and natural-language travel prototype logic.
- Preserved the illustrated travel landscape/footer treatment.
- Updated the visible version to v2.4.

## Run
Open `index.html` in a browser, or deploy the folder as a static GitHub Pages site.
