# DestyPoint v2.0

v2.0 updates the v1.9 prototype to the approved front-page design.

## Visual changes
- Removed “BÖRJA HÄR”
- Removed “Berätta vart du vill.”
- Kept the compact premium DestyPoint header
- Location-pin icon before “Beskriv din resa...”
- Added Från/Till date controls in one row
- Added large “Skapa min resa” CTA
- Inspiration is now a 2×2 grid on mobile
- Refined Weekend, Roadtrip, Sol & bad, and Natur & äventyr icons
- Added the gold travel line-art footer scene
- Added “DestyPoint v2.0” version label
- Preserved the existing prototype recommendation logic

## Functional fixes
- Date fields are initialized to today
- “Skapa min resa” and the spark button submit the trip
- Enter submits the trip
- Inspiration cards populate the trip prompt
- Date order is kept valid

## Run
Open `index.html` in a browser.
