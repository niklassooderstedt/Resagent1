# ✈️ ResAgent v0.6

v0.6 fokuserar på reseagentens intelligens.

## Nytt
- Resan analyseras utifrån destination, datum, resenärer, budget och prioriteringar.
- Destinationer tolkas dynamiskt.
- Inbyggda exempel för Japan, Kina/Kinesiska muren och Florida.
- Tre reseupplägg: balanserad, upplevelsefokuserad och budgetsmart.
- En enkel "ResAgent tänker så här"-sektion för att visa resonemanget bakom förslaget.
- Fortfarande helt utan externa API:er och riktiga bokningar.

## Test
Öppna `index.html` lokalt eller publicera projektet med GitHub Pages.

Nästa steg kan bli att ersätta de simulerade beräkningarna med riktiga rese-, flyg-, hotell- och kartdata.
