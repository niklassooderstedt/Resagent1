DestyPoint v1.7
=================
Design-focused rebuild of the mobile home screen.

v1.7 focus:
- Dark navy/gold visual system matching the agreed reference.
- DestyPoint branding and italic tagline.
- Natural-language trip description as the primary input.
- From/To dates.
- Inspiration cards.
- Existing prototype-style trip parsing retained in a lightweight frontend implementation.

This is a frontend prototype; live hotel/flight/booking APIs are not included.
